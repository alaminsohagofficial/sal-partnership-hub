# Salsabilah Amin Limited — Strategic Partnership & Cryptographic Hub

An interactive enterprise web application and cryptographic document verification prototype built for **Salsabilah Amin Limited (SAL)** and **SR Electronics Park**.

## 🚀 Live Modules
* **Strategic MoU Portal (`index.html`):** Interactive Memorandum of Understanding interface featuring dark/light theme support, metadata inspection, client-side digital sign-off, and print-to-PDF export.
* **Cryptographic Document Verifier (`verifier.html`):** Real-time SHA-256 integrity hash generator powered by the browser's native Web Crypto API (`crypto.subtle.digest`).
* **Enterprise Ledger Engine (`ledger_verifier.js`):** Modular Node.js class for generating and auditing tamper-evident SHA-256 document hashes.

## 🛠️ Architecture & Technologies
* **Frontend:** Semantic HTML5, Responsive CSS3 (Custom Properties), Vanilla JavaScript (ES6+)
* **Security:** Web Crypto API (SHA-256) & Node.js `crypto` module
* **Hosting:** GitHub Pages
